📊 Microsoft 365 Copilot Poisoning

Demonstrates attacks on M365 Copilot (Word, Excel, PowerPoint, Outlook) that work without code execution. Shows how poisoned web content leads to tracking pixels, malicious links, and data exfiltration through documents.

  • Document Poisoning: Tracking pixels and external references in Word/PowerPoint
  • No Code Execution: Attacks work through content manipulation alone
  • Spreadsheet Exfiltration: Excel formulas sending data to attacker endpoints
  • Email Attacks: Outlook drafts phishing emails with credential harvesting

🛡️ Defense Strategies

Each demonstration includes detailed defense strategies and mitigation techniques:

  • Input Sanitization: Strip malicious content before AI processing
  • Architectural Controls: Separate system prompts from user input
  • Code Review: Never blindly accept AI suggestions
  • Dependency Hygiene: Audit packages for poisoned documentation
  • Security Scanning: Automated detection of vulnerabilities
